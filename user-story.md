# User Story EPMCDMETST-67216

As a customer browsing the catalog, I want to search, filter, sort, and page through product listings so I can quickly find products that match my needs.

## Story acceptance
- The catalog loads products from the API.
- Users can search by product name or description.
- Users can filter by category and price range.
- Users can sort by price ascending or descending.
- Pagination controls help users navigate multiple pages.
- Invalid filter values return clear 400 responses.
